Danh sách API theo luồng hành trình FE
Khi vừa qua màn này, call tới API POST /api/agents:
Cụ thể sẽ update các thông tin sau:
gateway_url: url để call lấy câu trả lời agent
retrieval_url: url call lấy retrieval context từ knowledge retrieval
Khi chọn xong Tri thức (knowledge base) thì sẽ call tới api POST
/api/synthetic/v1/generate-testset
API sẽ trả testset_id khi chạy gen xong

--- Page 2 ---
Sử dụng api GET /api/testsets/v1/{testset_id}/testcases để lấy list testcase
để hiển thị.
Cho phép user sửa Câu trả lời, mỗi khi bấm Lưu nháp hay sang trang mới thì
sẽ gọi api /api/testsets/v1/testcases/{testcase_id} để update các testcase
đã được chỉnh sửa
Khi người dùng bấm duyệt, và click chạy kiểm định, call api
/api/testsets/v1/{testset_id}/versions/from-selection để tạo version mới của
testset từ list testcase được chọn.
Sau đó call tiếp api POST /api/runs/v1 để tạo 1 luồng chạy kiểm định 
Call tiếp api POST /api/runs/v1/{run_id}/execute để chạy luồng mới khởi tạo
